# Security

BTDeck sends keystrokes to other devices, so security problems matter.

## Reporting a problem

Please **don't** open a public issue. Report it privately through
[GitHub's security reporting](../../security/advisories/new) instead. Tell us what you found,
how to make it happen, and what harm it could do. We'll reply as soon as we can.

## What counts

- **Yes:** anything in this project. For example, a way for another device to send
  keystrokes through BTDeck, or to read what BTDeck saves.
- **No:** bugs in Android's own Bluetooth or in the tablet or laptop's Bluetooth. Please
  report those to the device maker. Feel free to tell us too, so we can work around them.
